# Design

## Context

本机 usage-skills/config.json 是技能身份登记，不等于安装证明。映射可能保留历史路径，也可能包含多个路径和没有路径的用户别名。

## Decisions

1. 出处清单读取整个映射，保持查询只读，不读取 sessions/history 或使用统计类型。
2. 每个映射条目逐路径检查普通文件和链接边界；只输出路径摘要，不输出原始本机路径。普通文件的元数据无效不等于文件不存在。
3. 单个存在文件为 present，多个不同存在路径为 ambiguous，全部缺失为 missing，无路径为 unmapped，链接/无法检查为 unresolved。所有路径检查结果均保留。
4. 元数据字段复用既有声明模型，用户声明只按精确 skillKey 应用，多个文件的候选分别保留，避免覆盖或短名猜配。
5. 输出独立 v2 报告，不冒充使用统计；--days/--strict/--markdown 等无关参数在文件读取前拒绝。

## Validation

覆盖未使用技能、损坏/不可用日志不影响查询、缺失及多路径、插件声明、用户冲突、链接拒绝、JSON 完整导出与输入文件不变。保留旧默认模式回归。
