# 集成 Skills 来源与 Hooks 统计

## Why
两个功能已在独立 worktree 交付，需要总控核对范围、合并共同入口并对合并后的主线执行统一验收。真实 Hook 验证记录尚未提交，需保留其证据边界。

## What Changes
- 核对共同基线、工作区、功能提交和专属验证，提交已完成的真实 Hook 验证文档。
- 先集成 Skills 来源，再集成 Hooks，保留两边测试和已实现的使用文档。
- 在读取日志及映射之前拒绝 Hooks 与 Skills 来源专用参数混用。
- 增加跨功能 CLI 回归，核对旧输出兼容、UTF-8 和真实 Hook 离线导入。
- 记录完整验收与最终本地提交，不推送、不归档、不删除 worktree。

## Non-goals
不增加来源认证、历史作者归属、Hook 常驻采集器或异步覆盖，不执行新的模型请求或发布。
